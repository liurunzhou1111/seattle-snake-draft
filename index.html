How to use

Set players to Mine or Taken. All other players remain Available. The app recalculates the best affordable completion automatically. Each teammate's browser tracks selections independently; there is no shared live state.

If accessing HTML through a chat or cloud preview, use the published GitHub Pages website URL instead. Do not open the HTML in Quick Look.
